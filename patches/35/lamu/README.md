# Moto G15 (lamu) patch set

This directory is intentionally kept minimal.

The branch is structured so that shared compatibility fixes stay under `patches/all/15`, while Moto G15-specific handling is limited to APEX and kernel requirements only.

- APEX compatibility: in this directory or its subfolders only
- Kernel compatibility: in this directory or its subfolders only
- Generic system/app patches: do not live here
